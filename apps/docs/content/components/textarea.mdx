## Installation

<InstallTabs cli="npx @dinachi/cli@latest add textarea" />

## Usage

```tsx
import { Textarea } from '@/components/ui/textarea'
```

Reach for it when the answer is a sentence rather than a value. Anything shorter than
that is an [Input](/docs/components/input), which sits on one line and does not invite
the reader to write more than they need to.

## Accessibility

<Callout tone="info" title="Labelling">
  A textarea needs a name like any other field. Pair it with a `<label htmlFor>`, or give
  it an `aria-label` where no visible label fits. Helper text and character counts belong
  in `aria-describedby` so they are read out with the field rather than skipped.
</Callout>
