## Image optimizers

`AvatarImage` preloads `src` and renders once it loads, which breaks with `next/image` and `loading="lazy"`. Add `keepMounted` to render the image right away. The fallback shows beneath it until the image loads, and stays if it fails.

```tsx
import Image from 'next/image'

<Avatar>
  <AvatarFallback>JD</AvatarFallback>
  <AvatarImage
    keepMounted
    render={<Image src="/avatars/jane.png" width={40} height={40} alt="Jane Doe" />}
  />
</Avatar>
```
