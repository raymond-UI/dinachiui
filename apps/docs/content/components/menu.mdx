## Filtering

Wrap the menu in `MenuFilter`, put `MenuInput` at the top of the popup, and the items inside `MenuList`. `MenuEmpty` shows when nothing matches. Filtering is a Base UI preview, so the API may change.

A filterable submenu needs its own `MenuFilter` around `MenuSub`. To separate groups, mark each group `data-filter-section` and start it with `<MenuSeparator data-filter-separator className="hidden" />`. `MenuList` shows the separator only between two visible groups.
