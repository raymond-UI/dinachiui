<Callout tone="info" title="How it works">
Unlike traditional component libraries, the DinachiUI CLI copies actual source code into your project. You get full ownership — modify variants, styles, and behavior freely.
</Callout>

## Commands

### `init`

Set up DinachiUI in your project. Creates `components.json`, injects the color theme, installs base dependencies.

<PackageManagerTabs type="exec" command="@dinachi/cli@latest init" />

### `add`

Add components to your project. Copies source code and installs dependencies automatically.

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add button" />

Add multiple at once:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add button input card" />

### Tiers

Components come in two tiers. The core tier is the 44 components built on Base UI. The
motion tier is 19 animated components that depend on [motion](https://motion.dev), so they
are installed separately rather than arriving with everything else.

Install every core component:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add --all" />

Install every motion component:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add --motion" />

Both, for the whole library:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add --all --motion" />

Naming a motion component installs it on its own, whichever tier flags you use or skip:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add marquee" />

### Alternative builds

A few components ship in more than one build: the same exports and the same usage,
implemented differently. Naming a component alongside `--motion` installs its motion build
rather than the motion tier.

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add toast --motion" />

The files land at the same paths the default build would have taken, so nothing in your app
changes and switching is a reinstall with `--overwrite`. [Toast](/docs/components/toast) is
the one that has a second build today.

### Other options

Overwrite existing files:

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add button --overwrite" />

### Global Install

For shorter commands, install globally:

<PackageManagerTabs type="global" command="@dinachi/cli" />

Then use `dinachi init` and `dinachi add button` directly.

## Configuration

After running `init`, your project will have a `components.json`:

```json
{
  "style": "default",
  "rsc": true,
  "tsx": true,
  "tailwind": {
    "css": "src/app/globals.css",
    "cssVariables": true
  },
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib"
  }
}
```
