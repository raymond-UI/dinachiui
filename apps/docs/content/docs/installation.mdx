## Whole tiers

`--all` installs the core library. `--motion` installs the 19 animated components, kept apart because they depend on [motion](https://motion.dev).

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add --all" />

<PackageManagerTabs type="exec" command="@dinachi/cli@latest add --motion" />

Naming a motion component installs it on its own, whichever tier flag you use or skip.

Using Next.js or Vite? Follow the [Next.js guide](/docs/installation/nextjs) or the [Vite guide](/docs/installation/vite).
